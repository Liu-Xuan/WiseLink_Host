# OCR runtime redistribution notice

This runtime contains Debian binary packages and language/data assets. The
exact binary/source package versions are recorded in
`debian/packages.tsv`; package copyright and license notices are copied next
to that inventory.

Any distribution of this runtime must also satisfy the corresponding-source
and notice obligations of those packages. In particular, Poppler utilities
and libraries include GPL-covered software, glibc includes LGPL-covered
software, and Tesseract/tessdata include Apache-licensed software. Release
owners must make the matching Debian source packages and patches available
through the release channel and complete the project's legal review. This
notice is an operational safeguard, not legal advice.
