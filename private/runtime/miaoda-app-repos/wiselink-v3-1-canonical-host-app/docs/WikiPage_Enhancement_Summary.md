# WikiPage 增强总结

## 改进目标

根据用户需求，对 WikiPage 进行以下增强：
- **保持信息简洁**：用户一入眼看到的是有价值的摘要信息，而非问题或过程描述
- **可展开的详细内容**：分析、依据、过程等信息通过折叠面板展开显示
- **借鉴静态页面设计**：采用静态演示页面的高质量 UI 设计模式
- **借鉴 LLM Wiki 概念**：增加事项间的交叉引用（关联事项）

## 已实施的改进

### 1. 主正文区增强 (WikiArticle.tsx)

**突出核心摘要**
- 将 `matter-summary` 改为 `matter-summary-highlight`
- 采用渐变背景 + 边框 + 阴影，参考静态页面的视觉风格
- 更大的字号（1.0625rem）和行高（1.7），突出显示
- 深色模式适配

**可折叠的详细章节**
- 每个 body section 变为可折叠的 `content-section`
- 增加 `section-header` 作为可点击的标题栏
- 增加 `expand-toggle` 按钮显示展开/收起状态
- 内容展开时带有平滑动画效果
- 章节整体带有悬浮效果和边框高亮

### 2. 侧边栏增强 (WikiSidebar.tsx)

**所有面板可折叠**
- 默认只展开"阅读目录"，其他面板折叠
- 每个面板标题可点击展开/收起
- 面板标题右侧显示数量徽章（badge-count）
- 平滑的展开/收起交互

**新增"关联事项"面板**
- 借鉴 LLM Wiki 的交叉引用概念
- 显示相关事项、依赖事项、阻塞事项、替代事项
- 每个关联显示关系类型徽章（相关、依赖、阻塞、替代）
- 支持点击跳转到关联事项

### 3. 类型定义分离 (types.ts)

新建 `types.ts` 文件，集中管理类型定义：
- `WikiMatter`: 扩展了 `relatedMatters` 字段
- `WikiPageProps`: 新增 `onNavigateToMatter` 回调
- `TocItem`: 目录项类型

### 4. 样式增强 (wiki.css)

**核心摘要样式**
- 渐变背景：`linear-gradient(135deg, #f0f9ff 0%, #e0f2fe 100%)`
- 蓝色边框和左侧强调线
- 轻微阴影效果
- 深色模式适配

**可折叠章节样式**
- 章节边框 + 悬浮效果
- 标题栏背景色区分
- 展开按钮图标旋转动画
- 内容展开时的滑动动画

**侧边栏增强样式**
- 数量徽章样式（badge-count）
- 可折叠面板的交互样式
- 关联事项的关系徽章（4 种类型配色）
- 悬浮效果和过渡动画

**图标样式**
- 使用简单的 emoji 图标（📄 ⏱️ 🕸️）
- chevron 图标（▼ ▲）

### 5. Mock 数据更新

在 `getMockMatter` 函数中添加了 `relatedMatters` 示例数据：
- WL-M015: 液压系统老化趋势分析（相关）
- WL-M042: 作动筒密封件改进项目（依赖）
- WL-M008: 起落架收放异常（旧版分析）（替代）

## 设计理念

1. **价值优先**: 核心摘要用渐变背景突出显示，确保用户第一眼看到的是有价值的结论
2. **渐进披露**: 详细的分析、过程、依据等信息默认折叠，需要时展开
3. **专业感**: 参考静态演示页面的配色和视觉效果，使用渐变、阴影、边框强调
4. **航空领域特色**: 保留 ATA 代码、机型、技术手册引用等航空维修领域特有元素
5. **知识关联**: 借鉴 LLM Wiki 的交叉引用概念，但保持航空领域的语义（相关、依赖、阻塞、替代）

## 与 LLM Wiki 的对比

**不采纳的部分**：
- 不采用 Markdown 作为存储格式（保留结构化的 WikiMatter 接口）
- 不采用 agent 编译流程（保留现有的 DocumentEvaluationPackage → ReportDraftPackage 流程）
- 不采用通用知识图谱（保留航空维修领域专用的事项-文档-证据关系）

**借鉴的部分**：
- ✅ 交叉引用机制（关联事项面板）
- ✅ 简洁优先的展示理念（折叠详细内容）
- ✅ 版本历史追踪（已有 workHistory）

## 后续可考虑的增强

1. **Markdown 导出**: 添加"导出为 Markdown"功能
2. **智能建议更新**: 当关联的文档或事项更新时，提示用户
3. **全文搜索**: 在 Wiki 内容中搜索关键词
4. **标签系统**: 为事项添加标签便于分类
5. **评论功能**: 允许团队成员对事项添加评论和讨论
