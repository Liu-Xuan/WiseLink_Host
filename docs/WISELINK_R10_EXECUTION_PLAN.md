## 第二步的具体接线

1. **选中评估点。** 当前 DocumentParsingPage 已读取选中 Criterion，但未传入 ContinuousReviewPanel；AppendReviewTextTurnRequest 无对应字段，Host 的 ReviewTurnTaskContract 将 selectedEvaluationItemId 固定为 null。使用一个可选字段贯穿页面、请求、既有 Turn JSON 与任务输入；由 Host 核对当前事项评估点，不依赖文本猜测。
2. **自动运行。** 当前 append 仅保存/回读。用既有 Turn/ActionAttempt 表达可恢复执行意图，解决“保存后派发前进程退出”的具体缺口。只对明确请求自动执行的新 Turn 领取；不重放历史 Turn 或已成功初始操作。优先验证 Hosted 云端主动领取，已有合适应用级入口时亦可使用；不能让开发 CLI 成为运行时依赖。
3. **共同上下文。** 从主文件业务语义、完整来源索引、精选已读片段、实际检索背景、工程师补充和讨论摘要装配评估前上下文。JobAid、Overall、Review 复用不同任务视图；评估后再附实际结果引用，避免把结果侧 EvaluationContext 当作首次评估前置而形成循环。
4. **真实执行投影。** 复用当前对话回读接口，向已授权页面提供按 Turn 的可见运行状态和失败原因。已有候选缺失不能等同“正在运行”；不另建前端业务状态机，不伪造百分比或取证活动。
5. **按需读取。** 将当前问题和选中 Criterion 交给 Agent，保留全量索引，按相关性/分批读取；不要将全部 availableSourceRefIds 一次塞入请求，也不要仅因来源数超过 100 而整轮失败。

运行入口尚待现场核实：普通妙搭应用详情 API 不支持 Hosted app 类型，不代表 Hosted 停机或不能自动运行。尚无云端消费者已部署的证据。
