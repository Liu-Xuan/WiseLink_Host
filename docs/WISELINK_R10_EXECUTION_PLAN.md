1. **选中评估点。** selectedEvaluationItemId 已贯穿页面、请求、既有 Turn JSON、回读和 Agent Task/Context，历史无字段 Turn 继续兼容。本轮实测发现页面默认显示 GOV-008、原提交却为 GOV-001；前端源提交 70a74167c 已集成 8fd75218d，统一默认选择、分类切换、URL 和发送焦点。

3. **授权领取与运行。** get_pending_review_turn 复用现有 owner、官方身份映射与 exact WorkItem service scope；ActionAttempt 在模型上下文准备前持久化。实际 SQL 中 actor_id 别名冲突已以唯一 CTE 别名修复，没有降低 RLS。官方 Hosted 原生 command cron 仍每 60 秒读取唯一 Skill 安装路径，该 Skill 已更新 c20；此前 c19 空闲自然 tick 已有 IDLE/无模型调用实证，安装不冒充新业务运行。
4. **页面真实状态。** 复用对话回读的 execution，显示状态、时间和失败原因。仅真实活动状态触发四秒只读刷新，终态和读取失败停止自动刷新；临时服务错误保留内容与草稿，权限失效清除不再可读内容。没有候选不等于正在运行。
5. **来源和材料。** 本次材料按需展开主文件、已保存输入/附件、正文引用目标和候选 SourceRef；10 处真实引用聚合为 6 个目标，点击来源已定位受控 PDF 第 5 页。选入、读取、引用、采用不互相冒充。c19 来源读取按 MCP 每批 100 项上限分批，不因总数超过单批上限拒绝讨论。
