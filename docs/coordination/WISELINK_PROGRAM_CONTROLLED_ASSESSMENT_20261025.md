## 3. 一份工作、两个投影

程序先通过正常 Host 路径取得准确原文、当前已获权事实、相关方法和旧工作基线。连续阅读保留跨页句子、表格标题/列头/单位/脚注、条件、否定、例外与期限；装配结果可映射回准确 DVI、parse 和原始条目。64 条接口/内联限制不是文件复杂度，也不能据此把部分材料标为整份已读。

实际模型输入须留存或能准确重建。复用现有检查点保存装配材料及确切序列化输入，并在调用前通过现有文件存储保留可读取快照；活动记录只保存该快照描述。正常页面按准确尝试惰性读取“本次材料”，重新核验当前用户、来源和旧工作访问权。准备记录不冒充已发送，收到响应不冒充模型正确理解了每段材料。完整响应在保存业务工作之前持久化。必要材料过大或缺失时明确范围/缺口；不静默截断、自动扩大目标或让模型自行缩小目标后宣布完成。

模型产出完整工程工作：当前综合判断、范围与条件、关键问题分析、措施与公司安排、待核与下一步、本轮变化。程序只做格式、引用、授权和范围等可判定检查；合法引用不等于语义支持。程序模式明确完成时，准确旧工作中的每个问题须在更新正文、未变键或退出记录中明确承接；未改问题不必重发正文。综合正文覆盖范围必须与合并后问题一致，局部综合不得冒充全事项综合。

保存经现有 Host 协议得到准确工作修订，程序随后独立 READ 该修订。工作正文立即可读，不等待综合；图上工作成果和综合所用来源都进入现有知识阅读的准确 workRef，旧综合不能误开当前新工作。初评使用公共确定性投影，实际消费刚读回的工作综合正文；不产生第二篇模型报告、不借用 Review 专用入口、不制造复核记录。后续独立综合请求按其真实请求身份显示，旧程序初评投影不遮蔽后继状态。

## 4. 恢复与显示

| 已发生事实 | 程序动作 | 页面/运行图含义 |
| --- | --- | --- |
| 完整响应已持久化，工作保存未成立 | 恢复同一响应的合法保存 | 已生成，尚未保存 |
| 保存请求确认丢失 | 通过原幂等身份核对/恢复 | 保存结果待核，不新造请求 |
| 工作已保存，综合未更新 | 读准确修订，仅恢复投影 | 工作可读，综合待更新 |
| 综合与工作同版，执行未终结 | 正常协议收尾 | 成果可读，执行仍在收尾 |
| 生成结果 UNKNOWN | 保留原请求与恢复关联 | 原请求结果待核；无实际核对动作不写“正在核对” |
| 页面读失败 | 重读现有成果 | 读取失败/上次获权观察，不触发模型 |
| 旧基线结果迟到 | 既有版本/CAS 校验 | 不凭到达时间覆盖当前结果 |

进展来自真实记录，不按计时器编造风险分析步骤。程序阶段观察不是独立权威任务状态，不证明 provider 终态。保存、综合、执行结束、批准、AEO 完成和效果验证分别显示。

## 5. 第一批联合验收

1. **材料**：取得范围和实际交付范围准确；抽查跨页、表格/脚注、否定和期限，映射可回到准确原文；已知缺失进入具体待核。
2. **内容**：评估可独立阅读；主要判断有证据、条件与下一步，已取得公司事实与系统建议分开；不靠填满问题数或风险分值验收。
3. **保存与读回**：合法 SAVE 取得准确工作修订；程序独立 READ 与正常用户读取一致。
4. **综合**：确定性投影真正消费同一保存修订，重要条件不丢失；投影失败时工作仍可读。
5. **恢复**：完整响应后保存失败、保存 ACK 丢失、投影失败、UNKNOWN、迟到旧基线各验证实际行为；不得重放 UNKNOWN。
6. **运行与阅读**：任务正常收尾；刷新、展开、切换和图下钻只读；权限/租户/对象变化清理缓存，父子共用同次获权读回。
7. **图文一致**：契约、接线页和嵌入图使用同一节点/完成含义；本地测试、发布和真实业务成功分开证明。

现有准确测试复用，缺口补测；测试数量不替代真实事项交付。第一批代码完成后再形成准确提交与安装/发布执行包，核对兼容次序及已有授权；不从本地准备推导线上已切换或新业务已成功。
