## 7. 质量标准

### 7.1 视觉还原
- 主要边界误差 ≤ 4px
- 字体、行高、密度精确匹配
- 阴影、圆角、透明度一致
- 动效帧对照或实际观察验证

### 7.2 交互完整
- 所有按钮、链接可用
- 状态恢复（返回、刷新）
- 键盘导航支持
- 错误态、加载态、空态

### 7.3 性能目标
- 首屏秒级呈现可用内容
- 冷开 p50 ≤ 1s, p95 ≤ 2s
- 同对象切换 p95 ≤ 100ms
- 不以骨架或旧缓存充当达标
