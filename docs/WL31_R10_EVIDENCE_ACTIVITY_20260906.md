## 本次变更

- 共同上下文的官方身份映射查询异常不再转换为 `false/ACCESS_DENIED`，真实失败向现有准备阶段错误处理传播；真正无映射时仍拒绝讨论与关联访问。
- 关联目标逐份隔离：一份文件或其授权查询失败标为 `UNAVAILABLE`，保留可公开的稳定原因码；其他已经独立核实授权、读到实际字节的资料继续可用。目录查询失败也明确记录原因。失败原因进入实际持久化快照，不只在内存补写。
- 复用 `action_attempt` 增加一个可空 `review_activity_json` 字段；无新表、队列、hash、baseline 或版本冻结。现有历史行不回填，既有 TaskEnvelope、ResultEnvelope、RLS、幂等、租约与业务采用边界不变。
- Host 在现有上下文和 SourceRef API 成功解析后记录实际观察：`CONTEXT_PREPARED` 与 `SOURCE_REFS_RESOLVED`。保存沿用当前授权后的 exact attempt、租户、事项、工程师、来源与租约代际，单条 SQL 原子追加，不改候选/任务正文。它不是网络送达确认、模型阅读证明或每次新下载文件的证明。
- 对话回读只投影安全活动字段，保留全部服务端记录，页面最多展示最近 100 条并明确早期条数。损坏的可选活动有独立可见错误，不遮住执行状态、候选或工程师输入。
- 回合页面显示活动和可定位来源，材料区明确 RAG 尚未接通；候选引用、取回片段与正式采用分开。不补造旧回合记录、不确认 ReviewAction。
