# Aily 原生聊天接入

复核页首屏直接挂载官方 `@lark-apaas/aily-web-sdk@0.0.12` 的 `initAgentChat`。输入、附件、消息与历史使用 Aily 原生界面；评估记录、模型选择和显式更新收在“评估记录与更新”下。此入口不再创建 Host 自制聊天表单。

现有 Aily Web SDK 渠道使用飞书账号、仅自己可用，匿名登录未开启。本次未改变这些设置。代码中的 channelToken 是官方嵌入代码使用的公开渠道路由标识，不是用户登录凭证。

## 已验证

- ESLint、前后端类型检查、Stylelint、生产前端构建通过。
- 本地真实浏览器已加载同一组件的 Aily 原生 WiseLink 窗口，显示原生 New Chat、Shortcuts、输入区。
- 尚未发布到 Host，尚未验证线上完整复核页布局。
- 三字段接线尚未在线运行验证；没有自动导入旧 Host 对话。原生对话不会自动成为评估输入。

## 已授权的上下文传输

用户已明确授权以下字段传输及向原主控任务转发代码与验证进度。三字段 SDK 接线已实现；开启渠道设置时 Mac 锁定，尚待解锁完成设置与实际接收验证。启用后，仅在用户打开文档或事项复核页时，通过官方 SDK `customParams` 发送下列当前页面讨论线索到同一个 WiseLink Aily 智能体：

| 字段 | 内容 |
| --- | --- |
| documentLabel | 当前主资料名称/编号 |
| documentRevision | 当前资料版本标签 |
| discussionScope | 文档或事项复核 |

这些前端可见字段仅用于定位讨论主题，不作为身份、权限、正式证据或审批依据。不传用户 ID、访问令牌、权限数据、资料全文、历史消息或内部任务标识。渠道继续使用飞书账号且仅自己可用。不扩大本次明确授权的字段范围。
