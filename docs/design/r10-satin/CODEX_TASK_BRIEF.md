## A：可立即做的前端材质改造
1. 复用 tokens/glass/motion 和现有布局组件，映射 src/theme.css 的四种材质。所有基础中性色 R=G=B。
2. 侧栏/顶栏使用同一磨砂配方；整张阅读面有实体填充和接触/落影；工程助手略退后；输入器是唯一明显悬浮的操作层。
3. 普通正文/列表行没有自定义渐变和外发光；选中控件只使用共享中性亮度配方。
4. 保持单左栏和上下文分组；资料库不增加第二个宽目录；1440 下助手约326px，阅读面可伸展。
5. 连续文档保留章节/表格/条件/例外/警示；不得变回每个 unit 一张折叠卡。
6. 主题和默认/最高/兼容集中到外观；没有自动档和演示档。最高不新增彩色光、旋转、粒子或鼠标视差。
7. 兼容档连 dialog backdrop blur 一并关闭，降低动效不隐藏任何业务信息。

## B：与 Host/Agent 同轮完成的语义与接线
1. 普通问题、材料、讨论、工作判断及候选可持久化，不以确认 ReviewAction 为前提；采用意见单独展示。
2. 本次材料区分选入、实际读取、结果引用、正式采用，不能统称 accepted。背景有用不要求先证明关联措施适用于本机。
3. 工作判断生成并保存后可以继续讨论；只有用户明确比较并采用具体草案，才走既有采用/并发/重算入口。
4. 使用同一评估前共同上下文的任务视图；初始分项、Overall、Review 不各自重建失去背景的输入。
5. 页面发送持久化意图，由已核实云端消费者自动执行并回写；不能用开发者电脑或主控手动 driver 代替。
6. 前端短轮询真实状态/活动。未支持运行中 steering 默认“下一轮指示”；不能用timer伪造暂停、已读或干预。
7. Chat Completions 或 stream=false 不是判断原生会话/工具循环的充分证据；按实际部署核实。
