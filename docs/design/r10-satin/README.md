## 分工与实施顺序

前端主控为既有任务「WiseLink 前端与 v0.6 接续」（`01a06014-5282-7f90-91bf-12759224d211`）。A、B、自动发送和默认焦点同步修复均已交付独立提交，由主控集成发布；未合入无关旧构型支线。以下是本轮采用的分工和后续接线原则。

1. **A 批次立即实施。** 前端只修改既有 client 材质、布局、连续阅读、来源导航及相关普通测试。先完成资料库 → 工程简报 → 连续文档 → 来源 → 同一对话的真实页面纵切。交付可单独集成的提交和浅/深/窄屏视觉证据。
2. **B 批次与 Host 同轮接通。** 主控负责 shared DTO、Host/Agent、云端自动执行、共同上下文、持久工作判断及真实状态/活动；前端按这些 read model 接“本次材料”“当前工作判断”“已采用意见”和“下一轮指示”。缺少字段需明确交接，不让 UI 自行推断后台事实。
3. **集成和运行。** 主控统一集成、兼容发布和既有 SB 777-34-0425 的真实页面连续往返。A 批次无需等待全部 B 字段或外部知识源齐备；但安装、截图和本地测试不等于 B 已运行。

## 与 Host 衔接的最小语义

| 页面能力 | 所需真值 | 不允许的替代 |
| --- | --- | --- |
| 当前问题／本次材料 | 同一事项的工作目标、材料身份、用途与可访问来源 | 另起一套前端材料库或从标题猜适用性 |
| 使用情况 | 选入、实际读取、结果引用、正式采用的分别记录 | 附件已保存就标记已读，候选引用就标记已采用 |
| 当前工作判断 | 已持久化的讨论/候选及其时间和来源 | 普通保存调用正式 ReviewAction |
| 已采用意见 | 既有采用入口的结果及业务版本 | 用最新聊天内容覆盖正式 current/STALE |
| 执行与活动 | 已保存意图、真实运行状态、取证活动与失败原因 | 无候选加计时器等同“运行中”，虚构进度、暂停回执 |
| 下一轮指示 | 已保存的新 Turn 与后续真实执行结果 | 未接 steering 时声称已干预当前运行 |

讨论中的业务 revision 变化应刷新工作上下文；授权收缩和正式提交仍保留原有保护。实际取证、依据和理由摘要可以展示，不输出模型私有原始思维链。RAG/构型未连接据实说明，同时继续分析可用材料。
