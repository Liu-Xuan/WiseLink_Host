# 辅助工作与讨论采纳 · 2026-09-11

用户最新要求：WiseLink 为工程师减负，充分利用 LLM。自由聊天后点击采纳，由模型生成变更清单，工程师确认或修订即可；不增加独立审核、权限选择或审批步骤。这里的采纳更新辅助工作认识，不等同于外部审批、发布和执行。

## 已实施的候选保存调整

移除 JobAid 候选保存中仅按来源类型拒绝来源陈述、风险评级、重要事件依据和措施状态的条件。移除本轮完成必有文档阅读的条件，允许基于实际已交付的工程师陈述或查询材料形成注明局限的工作。保留模型原文和分类，不通过确定性代码修改工程判断。兼容字段 SOURCE_FACT 在阅读界面显示为“来源陈述”；措施有效性显示为“评估认为有效”。这些字段不代表 Host 对事实或业务状态的确认。

LLM 负责分析支持关系、条件、反证与材料变化的影响。Host 仍核实引用注册、实际交付、当前授权、来源载体、版本、问题更新分区、事务/CAS、取消和确定性方法计算。没有新增用户确认。读取和后续工作保留来源身份及 candidateOnly；外部正式入口不由普通候选保存调用。

验证：19 项相关 Jest 测试，包含候选保存及既有 ReviewAction 入口；32 项模型循环测试；4 组实际 PostgreSQL 事务/权限/版本/保存复用测试全部通过，前后端类型检查通过。这是本地证据，尚未证明线上新版本保存成功。

## 尚待完成的交互

当前 DialogueAssessmentControl 仍要求先选原话保存贡献，再汇集补充发起更新。不能将更名视为已完成新交互。

目标：自由聊天 → 采纳并生成具体变更清单 → 编辑、取消个别项或一键确认 → 正常保存完整新工作版本 → 后续讨论使用新版本。清单须绑定当时实际工作和来源；未涉及问题保持原样。权限与版本核对在后台，只有实际冲突才提示。确认工作变更不串联 ReviewAction 正式采用或外部审批。
