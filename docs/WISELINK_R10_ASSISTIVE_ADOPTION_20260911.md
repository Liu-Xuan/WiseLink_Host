LLM 负责分析支持关系、条件、反证与材料变化的影响。Host 仍核实引用注册、实际交付、当前授权、来源载体、版本、问题更新分区、事务/CAS、取消和确定性方法计算。没有新增用户确认。读取和后续工作保留来源身份及 candidateOnly；外部正式入口不由普通候选保存调用。

依赖清单由 Host 从实际已校验引用补齐，避免正文已经引用却因未重复登记索引而拒绝整份工作；不引入新来源、不改支持角色或结论。
