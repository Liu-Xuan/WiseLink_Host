# Host 私人对话与显式评估更新

本次接入 `/dialogues` 和单会话地址。普通消息由已配置的 Aily 直接处理；文档复核页的普通聊天入口转入私人对话。原 Review 历史、明确的更新评估和正式采用操作继续保留。

- 会话默认仅本人可读，可无关注任务，也可关联最多八个获准任务。历史列表只提供本人会话标识和创建时间；每次正文读取重新检查对象授权。
- Host 保存原始用户输入、Aily 公开回答、生成时工作稿版本及实际上下文。Aily 获得工作稿摘要与有界近期历史，不宣称读取全文或无限会话记忆。
- 用户可选择自己输入或回答中的原话，关联到指定任务，标记问题、假设、纠正、约束或澄清。纠正可以明确替代一条同任务的有效贡献；撤回不抹除既往使用记录。
- “粘贴飞书片段”保存为用户提交摘录，不能证明原生作者或原消息真实性；默认仅保存，未验证原生自动回流、共享讨论和长期记忆撤回。
- 只有明确的评估更新请求才调用 OpenClaw。请求固定目标、业务版本、工作稿版本和所选贡献版本，保留原话与必要相邻问答。候选工作更新不等于正式采用。
- 同一请求重试恢复已保存结果；Aily 结果不明时保留记录并显示未知，不以新请求伪装恢复。公开 JSON 错误、流式断开和异步受理有区别。

数据库迁移 `0030_personal_dialogue.sql` 已按 dev → main 正常环境迁移执行，读回环境差异为空。新增四张表使用现有 actor transaction 与 RLS；旧 attempt 关联 Aily 查询继续兼容。

本地验证覆盖原文 UTF-16 选段、私人读回、上下文继承授权、并发 CAS、贡献纠正/撤回、评估请求幂等及前端权限失效清理；隔离 PostgreSQL 使用真实迁移和 RLS。技术发布与实际 Aily → 贡献 → OpenClaw → 新工作稿 → Aily 读回的业务验收分别记录，不能相互替代。
